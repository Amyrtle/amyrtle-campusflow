## 已验证的云端数据库结果

目标为 `secure-dragon-d6g1dce1lb03f43cf`，地域 `ap-shanghai`，共享 PostgreSQL。应用通过服务端 HTTPS 调用固定查询目录和 13 个业务事务操作；不使用控制面 SQL 作为业务运行接口，原生 `DATABASE_URL` 路径继续保留。

实际验收时间为北京时间 2026-10-26 19:18:28–19:18:37：

- 120 个同时发起的 HTTPS 报名请求竞争 100 个名额，100 个成功、20 个返回满额；数据库报名行数与活动计数均为 100。
- 20 个相同幂等请求只有 1 个创建、19 个重放，返回同一票据；改变内容后重放被拒绝。
- 20 个重复签到请求只写入 1 条记录，返回相同签到时间；非成员操作被拒绝。
- 报名插入触发唯一约束错误后，已增加的容量计数回滚，报名和计数均为 0。
- 报名字段校验、问卷空白/未知问题/必填/评分/选项/凭证校验、合法写读、重复反馈拒绝与收到反馈后的问卷锁定通过。

- 本轮随机合成组织、用户、3 个活动及其关联数据已删除；再次查询用户和活动均不存在。未使用真实报名数据。

## 已知限制

- HTTP 限流为单实例；AI 组织配额通过数据库原子预留。多副本部署前需完善共享限流。
- PGlite 只用于本地开发；生产使用真实 PostgreSQL 与 CloudBase 认证，服务端数据库凭证不得进入前端。
- 真实云验收覆盖服务器/public/无凭证数据面；普通用户 JWT 调用特权查询 RPC 返回 403/42501，云 API 的非组织成员请求返回 403、无身份请求返回 401。本地角色矩阵不等同于全部云端角色组合均已实测。
- 封面仅支持 URL，云存储上传界面尚未实现；自动保留期限清理、通知邮件、复盘 PDF、候补队列未实现，见 [路线图](ROADMAP.md)。
- 问卷复盘使用统计与反馈份数，模型不接收参与者名单或原始文本反馈。
- 本地未提供 Docker，镜像未构建运行；HTTP 函数部署不依赖本地 Docker，现已另外通过真实云端启动与数据库健康检查。
- 已在授权目标环境执行迁移、配置与合成数据写入，不能再声称“未执行任何云端写入”。未升级付费数据库、未开通收费模型；GitHub 源码仓库已按用户 2026-10-28 的明确要求公开，采用 MIT License。
