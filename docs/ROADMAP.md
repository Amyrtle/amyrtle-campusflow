# 后续迭代与上线前检查

更新：2026-10-26。共享 PostgreSQL 五个迁移和真实数据面 7 项验收已完成，合成数据已清理。以下区分剩余上线验证与后续产品能力。

## 完成当前云端 MVP

- 修复 HTTP 函数部署，核验真实函数状态、HTTPS 网关与数据库健康接口。
- 完成前端构建发布，验证实际地址、深层链接、CORS、登录后 API 与 CSV 下载。
- 核验真实邮箱验证码收发、注册/登录、令牌过期、退出与禁用用户；补真实普通用户 JWT 数据库权限及 API 跨组织验收。
- 在线上执行活动创建、匿名报名、凭证保存、签到、统计、问卷与复盘完整闭环。
- 使用 iOS Safari、Android Chrome 真机验证摄像头扫码、拒绝权限后的手动签到与弱网重试。
- 保持 AI 模板降级标识；如启用真实模型，先核验模型权限与费用，再检查结构输出、超时、配额和失败降级。
- 补齐运行日志脱敏、备份恢复、数据保留和删除流程；实际校园活动前明确负责组织的隐私联系人。

## Word 要求的后续交付

- 确认 GitHub/CNB 目标仓库、写权限和公开发布授权范围后推送，验证远程 CI，不把本地流水线文件当作远程执行结果。
- 云存储目前尚无上传界面，封面使用 URL；后续补有权限校验的上传、访问和删除。
- 维护部署教程、测试证据、产品截图与 TDP 技术实践材料，真实部署验证后再更新可用地址与完成状态。

## 产品迭代

- 将单实例 HTTP 限流升级为共享存储，支持多副本部署；AI 组织配额已经在数据库内原子预留。
- 增加通知邮件、活动变更订阅和必要提醒；当前组织邀请链接不等于已实现邮件自动通知。
- 报名取消和管理端删除已经实现；后续增加候补队列、工作人员交接与更完整审计查看。
- 增加可配置保留期限、定时清理与恢复演练。
- 增加嵌入中文字体并验证分页的复盘 PDF；原 Word 允许在基础 MVP 后实现。
- 扩大辅助技术、低端手机和弱网测试覆盖。

## 发布纪律

以真实验证结果更新状态。未部署不能写成已上线，明确模板不能写成真实模型。当前环境已授权的部署与合成验收继续执行；新增付费资源、影响既有生产数据或超出已有授权的公开发布应按具体范围处理。未确认结果的异步云任务须继续核查，不能仅根据“已提交”结束验收。
