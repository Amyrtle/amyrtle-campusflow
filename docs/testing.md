### 复验方式

该脚本是显式的云集成验收，不纳入默认 `npm test`。需要已经授权的测试环境、已部署的迁移、忽略目录中的服务端/公开凭证文件以及 `.local/cloud-tools.mjs` 管理工具辅助程序。脚本检查传入环境与三份配置一致，拒绝把密钥放入命令参数：

```powershell
node tests/cloud/verify-database.mjs --env-id <已核验的测试环境ID>
```

业务操作全部使用数据面 RPC。只有清理本轮合成数据时使用带明确 UUID 条件的管理 SQL；脚本不创建资源、不升级套餐、不自动重试结果不明的写入。失败时保留安全报告和合成标识，先核查清理结果再重跑。
