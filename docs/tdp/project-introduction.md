# Amyrtle CampusFlow 项目介绍

CampusFlow 是一款面向校园活动组织者的活动运营应用，目标是将自然语言策划、报名、现场签到和活动复盘放在同一条可追溯流程中。

项目重点是可验证的业务闭环。公开报名需要处理并发名额、重复请求和时间窗口；签到需要校验工作人员权限、保护电子凭证并保证重复扫码不重复计数；AI 方案必须经过结构校验和人工确认。统计和复盘使用实际数据库记录，模板输出与真实模型输出明确区分。

技术方案采用 React、TypeScript、Fastify 和 PostgreSQL，并以腾讯云 CloudBase Auth、PG、AI 和托管服务为云端集成目标。GitHub 与 CNB 配置用于版本管理、自动检查和构建。具体已验证范围见项目测试报告；云端认证、上线地址和真实模型调用只有完成对应验证后才可写入发布材料。
